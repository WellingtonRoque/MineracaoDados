# 📅 Cronograma da Disciplina

# Mineração de Dados (ISW-039)

**Curso:** Desenvolvimento de Software Multiplataforma (DSM)
**Instituição:** Fatec Indaiatuba – Centro Paula Souza
**Professor:** Prof. Dr. Wellington Roque

---

# Objetivo

Este cronograma apresenta o planejamento das atividades da disciplina de **Mineração de Dados** ao longo do semestre.

Cada encontro possui duração de **3 horas** e está organizado de forma incremental, permitindo que o Projeto Integrador evolua juntamente com os conteúdos estudados.

Ao final da disciplina, cada grupo terá desenvolvido uma solução completa de Mineração de Dados aplicada a um problema real.

---

# Organização das Aulas

Cada encontro será dividido da seguinte forma:

| Etapa                      | Tempo  |
| -------------------------- | ------ |
| Revisão da aula anterior   | 15 min |
| Conteúdo teórico           | 45 min |
| Demonstração prática       | 45 min |
| Exercícios em sala         | 45 min |
| Desenvolvimento do Projeto | 30 min |

# Observações

* O cronograma poderá sofrer ajustes ao longo do semestre conforme a evolução da turma.

* O versionamento do projeto deverá ser realizado continuamente utilizando Git e GitHub.
* Recomenda-se que cada grupo mantenha um histórico de commits, registrando a evolução do desenvolvimento do projeto.
