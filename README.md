# Bem-vindo!

Seja bem-vindo à disciplina de **Mineração de Dados**.

Vivemos em uma era em que dados são produzidos em grande volume por empresas, governos, dispositivos móveis, sensores, redes sociais e sistemas inteligentes. Entretanto, dados por si só possuem pouco valor. O verdadeiro diferencial está na capacidade de transformá-los em conhecimento para apoiar a tomada de decisões.

Nesta disciplina você aprenderá todo o processo de **Descoberta de Conhecimento em Bases de Dados (KDD)**, aplicando técnicas modernas de Ciência de Dados, Business Intelligence, Inteligência Artificial e Machine Learning para resolver problemas reais.

Ao longo do semestre, você desenvolverá um **projeto completo**, desde a definição do problema até a apresentação da solução final.

Todo o trabalho será desenvolvido utilizando ferramentas amplamente empregadas pelo mercado de tecnologia.

---

# Objetivos da Disciplina

Ao final da disciplina o estudante será capaz de:

* Compreender o processo de Descoberta de Conhecimento em Bases de Dados (KDD);
* Coletar dados provenientes de diferentes fontes;
* Construir processos de ETL;
* Preparar, limpar e transformar bases de dados;
* Aplicar técnicas de análise exploratória de dados (EDA);
* Utilizar algoritmos de Mineração de Dados;
* Aplicar conceitos de aprendizado supervisionado e não supervisionado;
* Construir dashboards para comunicação dos resultados;
* Desenvolver soluções baseadas em Inteligência Artificial;
* Publicar projetos profissionais utilizando GitHub.

---

# Competências Desenvolvidas

# Projeto Integrador

Toda a disciplina será desenvolvida por meio de um **Projeto Integrador**, representando um caso real de Ciência de Dados.

Cada grupo deverá escolher um problema real e desenvolver uma solução completa utilizando as técnicas estudadas durante o semestre.

O projeto será desenvolvido incrementalmente, acompanhando a evolução dos conteúdos apresentados em sala de aula.
